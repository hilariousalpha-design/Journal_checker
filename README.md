# JournalCheck

Static GitHub Pages journal lookup tool.

## Files
- `index.html` — complete UI and styling
- `app.js` — search, ranking, results, print/copy and URL search
- `data/journals.json` — validated 50,608-record master dataset
- `robots.txt` and `sitemap.xml` — basic SEO files

## Deployment
Keep the folder structure exactly as shown. GitHub Pages must serve `data/journals.json` at `/Journal_checker/data/journals.json`.

The dataset is a static master dataset and is not a live verification of external indexing services.
